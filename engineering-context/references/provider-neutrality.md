# Provider-Neutral Retrieval

Work with connectors and repository tools actually available in the environment.

- Inspect available tools before selecting an integration.
- Use documented search and retrieval functions.
- Do not assume Jira, Linear, GitHub, Confluence, Notion or another provider is installed.
- If a connector is unavailable, continue with accessible sources and state the gap.
- Search by project identifiers, issue keys, repository names, decision titles or exact terms.
- Prefer direct record retrieval and follow references selectively.
- Preserve canonical links, stable identifiers and source update times.
- Normalize information by meaning while retaining original field labels and identifiers.
