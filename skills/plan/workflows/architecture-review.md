# Architecture Review

## Purpose
Evaluate an architecture, design or implementation.

## Required references
- `../references/principles.md`
- `../references/evidence.md`
- `../references/quality-attributes.md`
- `../references/security-review.md`

## Procedure
1. Establish review scope and evaluation criteria.
2. Gather relevant documentation and implementation evidence.
3. Assess component boundaries and responsibilities.
4. Assess coupling, cohesion and dependency direction.
5. Assess scalability, reliability and performance.
6. Assess security and data protection.
7. Assess maintainability and testability.
8. Identify deviations from requirements and decisions.
9. Evaluate consequences and prioritise findings.
10. Provide actionable recommendations.

## Output
- Review scope
- Architecture summary
- Strengths
- Findings with evidence
- Severity and confidence
- Recommendations
- Unresolved concerns

Do not report subjective preferences as architectural defects.
