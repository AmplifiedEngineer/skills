# Evidence and Confidence

## Evidence classifications

- VERIFIED: directly supported by implementation or authoritative project evidence.
- INFERRED: strongly suggested by available evidence.
- ASSUMED: adopted provisionally to progress analysis.
- UNKNOWN: insufficient evidence to determine.

## Confidence

- HIGH: multiple consistent sources or direct implementation evidence.
- MEDIUM: credible but incomplete evidence.
- LOW: limited or indirect evidence.

## Finding requirements

Every material finding should include:
- Unique identifier
- Description
- Classification
- Severity
- Confidence
- Evidence
- Affected components
- Consequences
- Recommended action

## Evidence references

Prefer:
- File paths
- Symbols and identifiers
- Configuration keys
- API definitions
- Tests
- Relevant documentation
- Commit or change references when available

Never fabricate line numbers, implementation behaviour or test results.

Distinguish absence of evidence from evidence of absence.
