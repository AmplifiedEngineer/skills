# Verification

1. Derive checks from changed behaviour and acceptance criteria.
2. Inspect existing test and validation conventions.
3. Select relevant available checks, starting with focused checks.
4. Run checks appropriate to the task, environment and authorization.
5. Inspect results and distinguish pass, fail, skipped and not run.
6. If a check fails, determine whether the change caused it; fix in-scope issues or report the blocker.
7. Review the final diff and ensure the report matches observed evidence.

Report checks actually run and checks not run with concise reasons. Do not invent coverage, results or guarantees.
