# Security Review

Assess relevant security boundaries and failure modes.

## Areas
- Authentication
- Authorisation
- Identity propagation
- Secrets management
- Data classification
- Encryption
- Input validation
- Injection risks
- Trust boundaries
- Supply-chain dependencies
- Auditability
- Network exposure
- Tenant isolation
- Data retention

## Procedure
1. Identify assets and sensitive data.
2. Identify actors and trust boundaries.
3. Identify entry points and privileged operations.
4. Identify threats and abuse cases.
5. Assess existing controls.
6. Identify gaps and mitigations.
7. Identify verification requirements.

Use recognised threat-modelling approaches where appropriate.

Do not claim security certification or compliance without evidence.
