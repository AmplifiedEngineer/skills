# Quality Attributes

Evaluate attributes relevant to the actual system.

## Attributes
- Performance
- Scalability
- Availability
- Reliability
- Resilience
- Security
- Privacy
- Maintainability
- Testability
- Interoperability
- Portability
- Observability
- Accessibility
- Cost efficiency

## Evaluation

For each relevant attribute:
1. Establish the requirement.
2. Identify measurable expectations where possible.
3. Identify architectural mechanisms.
4. Identify trade-offs.
5. Identify failure scenarios.
6. Define validation methods.

Do not claim an architecture is scalable, secure or highly available without supporting reasoning and evidence.
