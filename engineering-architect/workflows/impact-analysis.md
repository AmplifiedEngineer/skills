# Change Impact Analysis

## Purpose
Identify the likely impact of a proposed change before implementation.

## Required references
- `../references/repository-investigation.md`
- `../references/knowledge-model.md`
- `../references/evidence.md`

## Procedure
1. Define the requested change and affected behaviour.
2. Identify relevant requirements and decisions.
3. Locate affected components and interfaces.
4. Trace direct and indirect dependencies.
5. Identify affected data structures and migrations.
6. Identify affected integrations and consumers.
7. Identify security and operational implications.
8. Identify tests and documentation requiring changes.
9. Estimate implementation complexity and risk.
10. Identify sequencing and compatibility concerns.

## Output
- Change summary
- Affected components
- Dependency impact
- API and data impact
- Security and operational impact
- Required tests
- Documentation impact
- Risks and implementation considerations

Distinguish confirmed impacts from potential impacts.
