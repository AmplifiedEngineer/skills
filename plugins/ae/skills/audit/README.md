# Audit

Audit an unfamiliar or long-lived repository and report its health, with a file:line citation for every finding and a task plan a newcomer can act on.

Install this directory as audit under .claude/skills/, .agents/skills/, or ~/.agents/skills/. Read SKILL.md first and load only the references and templates a step names.

The skill reads the repo and reports. It changes no code, runs no project code, and saves the report only when asked.
