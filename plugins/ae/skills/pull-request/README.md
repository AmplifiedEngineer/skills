# Pull request

Open a small, readable draft pull request for the current branch, with plain git and gh.

Install this directory as pull-request under .claude/skills/, .agents/skills/, or ~/.agents/skills/. Read SKILL.md first and load only the template a step names.

The skill needs git and the GitHub CLI (gh). It opens the pull request as a draft and never force-pushes. To commit first, use the commit skill.
