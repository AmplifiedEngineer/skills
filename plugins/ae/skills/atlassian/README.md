# Atlassian

Choose the Atlassian MCP server, acli or twg to reach Jira work items, Confluence pages and Teamwork Graph data, and use each one correctly.

Install this directory as atlassian under .claude/skills/, .agents/skills/, or ~/.agents/skills/. Read SKILL.md first and load only the references a step names.

The skill reads by default. It writes to Jira or Confluence only with your confirmation or when you asked for that write.
