# Engineering Standards

Guard rails for any agent that designs or writes code, prepares a pull request, plans tests or plans a deploy.

Other skills and the agent load this skill for code work. Users do not call it by name. For JavaScript and TypeScript, Python and Rust, it also carries language references under `references/`, loaded only when the code touches those languages. The project's own conventions, config and linters win where they disagree with the references.

Install this directory as engineering-standards under .claude/skills/, .agents/skills/, or ~/.agents/skills/. Read SKILL.md.
