# Writing Style

One plain, simple-English standard for prose a person will read: PR text, commit messages, review comments, replies, tickets, docs, ADRs and chat replies.

Other skills and the agent load this skill when they write prose. Users do not call it by name.

Install this directory as writing-style under .claude/skills/, .agents/skills/, or ~/.agents/skills/. Read SKILL.md first and load only the references it names for the kind of text you write.
