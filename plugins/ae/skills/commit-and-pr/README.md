# Commit and PR

Commit finished work and open a pull request, with plain git and gh.

Install this directory as commit-and-pr under .claude/skills/, .agents/skills/, or ~/.agents/skills/. Read SKILL.md first and load only the template a step names.

The skill needs git and the GitHub CLI (gh). It never commits on the default branch, never force-pushes and opens the pull request as a draft.
